# llm-api - releases

Installers for **llm-api**: run AI models on your own computer and use them
from any device, with an OpenAI-compatible API and a web console (Hebrew and
English).

**Download page:** https://yaarilevrosen-cpu.github.io/llm-api-releases/

| Platform | How |
|---|---|
| Windows 10/11 (64-bit) | `llm-api-setup-<version>.exe` from the [latest release](https://github.com/yaarilevrosen-cpu/llm-api-releases/releases/latest) |
| Linux, Raspberry Pi (64-bit) | `curl -fsSL https://yaarilevrosen-cpu.github.io/llm-api-releases/install.sh \| sh` |

Every file has its SHA-256 in `SHA256SUMS` next to it in the release, and on
the download page. The Linux script checks it before installing anything.

This repository holds only the download page and the release files. The
source code is not published here. See [NOTICE.md](NOTICE.md) for the terms
and the third-party licenses.
